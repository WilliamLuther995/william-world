# WILLIAM · Personal Universe

WILLIAM 个人网站的开场序幕与视觉小馆。名称暂定，设计与内容会持续迭代。

## 当前体验

- 暗色雾幕、胶片颗粒与微尘；保留青黄初始配色，可切换橙红配色。
- 远、中、近三层天气粒子：秋叶、小雨、大雨、小雪、大雪，可关闭；默认秋叶更密集、落速更快。
- 点击页脚“天气／Weather”打开工作室，实时调整数量、落速、风力、大小、不透明度和空间层次；每种效果单独保存参数，支持重置、导出和导入。
- 标题从左到右逐字渐亮，然后整体闪烁。
- 冬装小胖子连续跑过，剪影与脚底扬尘只在标题字形内可见。
- 欢迎语渐显后点击进入过渡页，支持跳过与重播。
- 默认英文，支持中文与日语；保存当前浏览器的语言、配色选择。
- 适配移动端、键盘操作和减少动态效果偏好。
- 进入后展示“小小奇遇图鉴”：天体主视觉与光、雨、冬日三幅原创视觉习作。
- 点击习作打开原生弹窗，阅读三语短文；支持 Escape 关闭及焦点返回。内容为创意场景，不代表个人履历或真实作品经历。
- 卡片有指针光影，减少动态效果下取消装饰运动；雾幕按经过时间更新，避免高刷新率屏幕加快运动。
- 配色保留青黄与橙红，新增深红与浅蓝；四套均可切换并保存选择。
- 新增独立的收藏夹图书馆 `dist/bookmarks.html`：本机读取 Edge 收藏，支持文件夹、关键词、域名、重复网址筛选，排序与卡片／列表切换，以及网页入口、文本摘要和主动加载的网页画面。

## 收藏夹图书馆

双击 `start-local.cmd` 启动本机工具，然后打开 `http://127.0.0.1:4173/bookmarks.html`。也可在项目目录运行 `node local-server.cjs`。本机工具只绑定本机地址，只读 Edge 的收藏文件，不修改浏览器，也不将收藏写入项目或上传到仓库。

页面自动读取可用的 Edge 配置，点击读取按钮刷新。点击“预览”提取公开网页的标题、介绍与正文；点击“加载网页画面”尝试嵌入原网页。内网、需要登录、脚本渲染或限制嵌入的站点可能无法完整预览，始终提供原网页入口。预览不使用 Edge 的登录凭证。只在点击后访问站点，不批量抓取全部收藏。

在线版或直接打开 HTML 时，使用“导入文件”读取 Edge 导出的收藏 HTML、Edge Bookmarks JSON 或工具兼容的 JSON 数组。数据在浏览器内处理。可勾选“保存在此浏览器”；“清空本页”移除该浏览器保存的副本，不删除 Edge 原收藏。

收藏页目前为中文；个人网站原有英／中／日界面保留。导入文件上限10 MB，最多30000个 HTTP/HTTPS 入口；列表分批展示，每批90个。

## 打开网站

无需安装依赖或构建，直接用浏览器打开 `dist/index.html`。

也可以在仓库目录启动本地服务器：

```sh
python -m http.server 4173 --directory dist --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4173/`。网络字体不可用时会回退到系统字体。
